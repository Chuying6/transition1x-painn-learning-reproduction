# Result source data

These tables are the machine-readable source data for the figures in `figures/`.

- `expanded_training_history.csv` contains all 30 epochs from the persisted JSON log of the complete expanded-data rerun.
- `expanded_training_complete.json` is the unrounded training record written directly by the trainer. The best checkpoint by validation force RMSE occurred at epoch 23.
- `fixed_test_comparison.csv` compares three checkpoints on the same fixed test split from `mini_diverse_equal_transition1x.h5` (150 configurations, 8 formulas, 15 reactions). The table records the evaluation file's SHA-256 so identity is checked rather than inferred only from matching split sizes.

All runs used one random seed (`7`). The comparison therefore demonstrates the observed result for this reproduction run, not uncertainty across repeated trainings.

The equal-size diverse and expanded training selections were generated by the
original `global_choice_v1` sampler. They are not nested: 146 of the 306 training
reactions in the equal-size set also occur in the expanded set (47.7% retention).
Consequently, their comparison changes both reaction count and the identities of
some sampled reactions. All reported fixed-test metrics nevertheless use the same
150-configuration test split from `mini_diverse_equal_transition1x.h5`.
